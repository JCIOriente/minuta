# How-to guides

**English** | [Español](README.es.md)

Each guide helps you finish one task. Open the one that matches what you want
to do and follow it from top to bottom.

| I want to... | Guide |
| --- | --- |
| Go from a recording to minutes I can send, in one pass | [From a recording to meeting minutes](worked-example.md) |
| Write my own template, or change a built-in one | [Add and override your own templates](custom-templates.md) |
| Choose the whisper model and the language model | [Set up an LLM and a whisper model](llm-and-whisper.md) |
| Fix a problem that `minuta doctor` shows | [Fix what doctor reports](fix-doctor.md) |

New to minuta? Install it first with the [installation guide](../install.md),
then read the guides in this order: fix what doctor reports, set up the models,
then the worked example.

These guides show how to do a task. For a complete list of commands, settings
and template keys, use the reference pages: [Reference](../reference.md) and
[Templates](../templates.md).
