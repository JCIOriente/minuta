# Guías prácticas

[English](README.md) | **Español**

Cada guía te ayuda a completar una tarea. Abre la que corresponda a lo que quieres
hacer y síguela de arriba abajo.

| Quiero... | Guía |
| --- | --- |
| Pasar de una grabación a un acta que pueda enviar, de principio a fin | [De una grabación al acta de una reunión](worked-example.es.md) |
| Escribir mi propia plantilla o cambiar una integrada | [Agrega y reemplaza tus propias plantillas](custom-templates.es.md) |
| Elegir el modelo de whisper y el modelo de lenguaje | [Configura un LLM y un modelo de whisper](llm-and-whisper.es.md) |
| Resolver un problema que muestra `minuta doctor` | [Resuelve lo que reporta doctor](fix-doctor.es.md) |

¿Es tu primera vez con minuta? Primero instálala con la
[guía de instalación](../install.es.md) y luego lee las guías en este orden:
resolver lo que reporta doctor, configurar los modelos y, por último, el ejemplo
completo.

Estas guías explican cómo hacer una tarea. Para la lista completa de comandos,
ajustes y claves de plantilla, usa las páginas de referencia:
[Referencia](../reference.es.md) y [Plantillas](../templates.es.md).
